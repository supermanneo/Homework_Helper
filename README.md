# 嘟嘟的学习乐园

使用 Node.js 22+、Vite 和原生 JavaScript 构建的静态复习网页。无需后端、数据库或外部字体/CDN，适合 GitHub Pages 和华为平板浏览器。

## 科目首页

首页提供英语、数学、语文入口。各科目可通过顶部“乐园首页”返回；整体使用清晰对比和大按钮，面向一年级孩子。

### 语文：拼音认读表

- 点击“开始学语文”打开全部拼音认读表：23个声母、24个韵母、16个整体认读音节，共63项，同时展示，不需切换分类。
- 韵母分为单韵母、复韵母、特殊韵母er、前鼻韵母及后鼻韵母；无声调。本轮只供静态认读，不播放发音、不考试、不计分，也不显示输入键盘。
- 每项采用四条线形成的标准四线三格，使用站点自带SVG字形，包括单层a、g和ü，按字母的升部/降部位置排列，不依赖外部字体或系统字体。
- 平板横屏三类并排，随可用高度调整拼音大小，1024×600、1280×800、1440×900全部同屏，不隐藏或裁切内容。手机和窄屏纵向排列，保留完整内容并允许必要滚动。

### 数学：加减法与九九乘除法

进入数学后选择“加减法练习”或“乘除法练习”。两类共用10题整卷、数字大按键和计分流程，历史成绩分开记录；“再来一轮”保持当前类型，可通过“数学练习”返回选择页。

#### 加减法范围

- 每轮随机10题，5道加法、5道减法；整数操作数在1～99，正确答案在16～99，题目和正确答案不出现0或100。
- 同轮题目不重复，加法交换操作数视作相同题；所有题目在同一页展示，窄屏可滚动查看。
- 点击答案框，用网页常驻0～9数字按键输入；当前题高亮，另有“下一题”“删除”“清空”。不会按输入位数自动跳题，不弹系统键盘；也可使用实体键盘，答案框中Enter跳到下一题，最后一题Enter交卷。
- 输入0～100的整数，不能留空或填小数、负数、字母；非法输入会明确提示，不清空已填答案。
- 完成全部10题后统一提交，每题10分、满分100分，显示逐题对错及错题正确答案。提交前不展示正确答案，提交后锁定。
- “再来一轮”重新出题。刷新或离开练习不保留答案；交卷得分保存在当前浏览器，不提供账户或云同步。
- 数学不依赖英语词库，词库加载失败时仍能返回首页进行数学练习。
- 输入仍允许0～100作为孩子提交的错误答案，满分仍为100分；该范围不代表出题范围。

#### 乘除法范围

- 每轮随机10题，乘法和除法各5题，使用九九乘法口诀范围。
- 乘法两个因数都是1～9，积为1～81；除法由这些乘法反推，被除数1～81，除数和商都是1～9，全部整除、无余数。包括乘以1、除以1及商为1，不出现0。
- 不适用加减法“答案大于15”的规则。输入仍接受0～100的整数作为可能的错误答案，不提前透露正确答案范围。
- 同轮乘法交换因数算重复（3×4与4×3不会同时出现）；除法算式不重复，但允许乘法对应的除法同时出现，如3×4与12÷3。
- 输入、每题10分、整卷提交、错题反馈、交卷锁定及重开方式与加减法一致。

### 平板横屏布局

针对华为 MatePad Pro 13.2，横屏宽度至少960 CSS像素时采用紧凑布局：压缩页头和留白、首页三科目并排、数学两列五行、成绩条与逐题反馈紧凑展示。保留20px正文和至少56px的主要触摸目标，不使用隐藏溢出来裁切内容。

浏览器缩放、地址栏和系统键盘会影响实际可用尺寸；手机/竖屏、键盘弹出、异常提示或大量英语错题时允许自然滚动。物理分辨率不等于网页CSS尺寸，最终仍需平板实机检查。

### 儿童专用输入区

英语挑战和数学作答时显示网页大按键，横屏常驻题目右侧，手机/竖屏放在题目下方并允许自然滚动，不浮层遮挡题目；不使用系统软键盘。数学键盘上方同步显示当前算式和已填答案，便于窄屏操作。首页、简单/困难四选一、已提交反馈和成绩页不显示。所有字母格、数字框和按键至少56px，当前输入位置蓝色高亮。

- 英语：a～z顺序排列。点任意下划线定位，点字母填入后自动前进，末格停留；可点回覆盖。删除当前字母，当前格为空时回退删除；清空重填。每格填完后手动提交，未填完整会定位到空格并提示。原有空格、撇号和连字符保留，无需输入。
- 数学：点任意答案框切换，切题保留已填答案。“下一题”循环切换，不自动交卷；原有整卷提交按钮及0～100整数校验保留。最多输入3位，超出时提示，不丢失已有输入。
- 实体键盘：字母/数字正常输入，Backspace删除、Delete清空；英语在字母格中按Enter提交，左右方向键定位。数学在答案框中按Enter跳题，最后一题Enter交卷。
- 输入区按类型共用布局和按键接口，未来可扩展语文；本轮不新增语文题目或拼音/手写键盘。

## 本地运行

在当前目录打开 PowerShell：

```powershell
npm install
npm run dev
```

打开终端输出的网址，通常为 `http://localhost:5173`。关闭服务按 `Ctrl+C`。
开发端口被占用时会明确报错，不会悄悄切换端口。也可以在 VS Code 的“终端 → 运行任务”中选择“本地运行单词复习”或“构建静态网页”。

同一 Wi-Fi 下的平板可打开 `http://电脑局域网IP:5173`。电脑需要允许 Node.js 通过专用网络防火墙，不要关闭整个防火墙。不要把本地开发服务器暴露到公网。

```powershell
npm test
npm run build
npm run preview
```

`npm test` 使用 Node.js 内置测试运行器；`npm run preview` 在本地预览构建结果，默认地址 `http://localhost:4173`。

## 编辑单词本

编辑根目录的 [单词本.txt](./单词本.txt)，使用 UTF-8 保存，每行一个词条：

```text
dog#狗
apple#苹果
beautiful#美丽的
```

空行会忽略，格式错误和重复行会显示提示。至少需要两个英文字母才能出题。支持英文撇号、连字符和空格，不挖空标点。网页会保留英文原始大小写。单词本是公开网页资源，请勿写入私人信息。

修改后，本地刷新页面即可；线上需重新构建部署。进入首页的“英语”，选择“全部单词复习”的难度，每种难度均将全部有效词条随机打乱、每词考一次（当前35题），不再提供随机10词复习：

- **简单**：保持原有1～3个缺字规则、中文释义和四个补全字母组合选项。
- **困难**：约三分之二字母被挖空（向上取整，至少留1个字母），保留中文释义，仍用四选一。
- **挑战**：只看中文释义和一字母一个下划线，点下划线后用网页字母键逐格输入，填满后手动提交；无选项。空格和标点保留，不提示任何英文字母。忽略大小写，未填完整不计分，其余按整词判断。

难度入口显示规则，答题页和成绩页标明当前难度。每题只计分一次，答题后点击下一题，完成后展示成绩和错题。“再来一轮”沿用当前难度并重新随机出题；可返回英语页切换难度。刷新页面会重置未完成的进度。

简单、困难的选项是按缺字位置顺序补入的字母，不是完整单词；选择后以蓝色填回空位。挑战输入的字母及提交后的完整拼写也以蓝色展示。选错时均保留实际作答，下方单独展示正确答案；进入下一题会恢复新的缺字题目和空白草稿，无需切换系统输入法。

## 历史成绩

通过顶部“成绩记录”或英语成绩页的“查看得分曲线”进入，切换5个分组：英语·简单、英语·困难、英语·挑战、数学·加减法、数学·乘除法。数学两个类型各自保存最近20次；新增类型不会清空或改写原有加减法记录。

- 每组保存最近20次完成练习的整数得分（0～100）和完成时间。UTC ISO时间戳存储，按设备本地时区显示，明细精确到秒，曲线日期/小时标签如“2026-11-12 14时”。
- 曲线按完成顺序等距排列，每轮一个点，同小时多轮不合并或取平均；横轴标签过密时抽样，点击或键盘聚焦任意点可查看该轮完整时间及得分。
- 旧版纯分数记录保留并标注“时间未知”，不会补造时间；新旧混合兼容，成功追加后统一保存为`{ score, completedAt }`结构，未知旧时间为`null`。
- 英语按正确率四舍五入，数学沿用每题10分；只保存得分和完成时间，不保存题目、答案等其他数据。
- 未完成、中途退出不记录；完成后仅保存一次，重开是新的一轮。保存失败重试沿用原完成时间，不改为重试时刻；时间取自设备时钟，请保证设备时间正确。
- 使用当前站点的浏览器localStorage；刷新、关闭重开仍可读取，但手机和平板、不同浏览器、本地与线上站点不互通。清除站点数据、隐私模式或浏览器存储策略可能导致记录丢失。
- 读取/写入失败或已有数据损坏会明确显示错误；不会伪装保存成功或覆盖损坏数据，本轮成绩仍正常显示，可点击“重试保存”。必要时先备份该站点存储，再处理权限或损坏数据；清理站点数据会删除本浏览器的历史。
- 曲线放在独立页面，不挤占数学10题或英语答题区。0次显示空状态，1次显示单点，最多20点，纵轴固定0～100分。

1. 将项目提交并推送到仓库的 `main` 分支（本次开发不会代为提交或推送）。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 推送到 `main` 或在 **Actions → Deploy to GitHub Pages → Run workflow** 手动触发。
4. 等待部署工作流成功，在 Pages 设置页打开网址。当前仓库的预期地址为 `https://supermanneo.github.io/Homework_Helper/`。

若默认分支不是 `main`，修改 [.github/workflows/deploy.yml](./.github/workflows/deploy.yml) 中的分支配置。构建使用相对资源路径，支持仓库子路径和自定义域名。部署过程中会先测试、再构建，失败不会发布。

## 平板操作

- 支持横竖屏，横屏紧凑布局的英语选项至少64px高，其他布局至少82px高；选中后锁定，防止连续点击重复计分。
- 中文释义在单词右侧，窄屏或长单词时允许换行。
- 英语简单/困难支持键盘1–4作答、Enter继续，挑战用逐格字母输入、Enter提交；数学用网页数字按键，支持实体键盘和Tab导航，不主动弹出系统键盘。
- 不依赖第三方在线资源；首次加载仍需要网络，不包含离线 PWA 缓存。
- 本地尺寸模拟无法代替真实华为平板浏览器，建议上线后用实际设备验收。

## 科目扩展

[src/subjects.js](./src/subjects.js) 定义带类型区分的科目注册表：共有 `id`、`name`、`description`、`icon`，`kind` 决定练习能力。英语（`word-review`）提供 `load()`、`createQuestion()`；数学（`worksheet`）提供 `createWorksheet()`、`gradeWorksheet()`；语文（`pinyin-reading`）展示拼音认读表，分类及自带字形位于 [src/pinyin.js](./src/pinyin.js)。文字选择题、整卷数字作答及静态认读分别渲染，不强行共用不适合的题型。数学规则与计分位于 [src/math.js](./src/math.js)，测试位于 [test/math.test.js](./test/math.test.js)。

需求以 [需求文档.md](./需求文档.md) 为准；后续先记录需求变更，再实现。
