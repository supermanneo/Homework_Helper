# 词间 · 单词复习

使用 Node.js 22+、Vite 和原生 JavaScript 构建的静态复习网页。无需后端、数据库或外部字体/CDN，适合 GitHub Pages 和华为平板浏览器。

## 本地运行

在当前目录打开 PowerShell：

```powershell
npm install
npm run dev
```

打开终端输出的网址，通常为 `http://localhost:5173`。关闭服务按 `Ctrl+C`。
开发端口被占用时会明确报错，不会悄悄切换端口。也可以在 VS Code 的“终端 → 运行任务”中选择“本地运行单词复习”或“构建静态网页”。

同一 Wi-Fi 下的平板可打开 `http://电脑局域网IP:5173`。电脑需要允许 Node.js 通过专用网络防火墙，不要关闭整个防火墙。不要把本地开发服务器暴露到公网。

```powershell
npm test
npm run build
npm run preview
```

`npm test` 使用 Node.js 内置测试运行器；`npm run preview` 在本地预览构建结果，默认地址 `http://localhost:4173`。

## 编辑单词本

编辑根目录的 [单词本.txt](./单词本.txt)，使用 UTF-8 保存，每行一个词条：

```text
dog#狗
apple#苹果
beautiful#美丽的
```

空行会忽略，格式错误和重复行会显示提示。至少需要两个英文字母才能出题。支持英文撇号、连字符和空格，不挖空标点。网页会保留英文原始大小写。单词本是公开网页资源，请勿写入私人信息。

修改后，本地刷新页面即可；线上需重新构建部署。首页提供两种模式：

- **随机复习**：随机抽取至多 10 个不重复单词，不足 10 个时使用全部有效词条。
- **全量复习**：将全部有效词条随机打乱，每词考一次；当前词库共 23 个词，即每轮 23 题。

两个入口显示题量，答题页和成绩页显示当前模式。选项是按缺字位置顺序补入的字母，不是完整单词。答题后点击下一题，完成后展示成绩和错题。“再来一轮”沿用当前模式并重新随机出题；可返回首页切换模式。刷新页面会重置本轮进度。

## GitHub Pages

1. 将项目提交并推送到仓库的 `main` 分支（本次开发不会代为提交或推送）。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 推送到 `main` 或在 **Actions → Deploy to GitHub Pages → Run workflow** 手动触发。
4. 等待部署工作流成功，在 Pages 设置页打开网址。当前仓库的预期地址为 `https://supermanneo.github.io/Homework_Helper/`。

若默认分支不是 `main`，修改 [.github/workflows/deploy.yml](./.github/workflows/deploy.yml) 中的分支配置。构建使用相对资源路径，支持仓库子路径和自定义域名。部署过程中会先测试、再构建，失败不会发布。

## 平板操作

- 支持横竖屏，选项触摸区域至少 82px 高；选中后锁定，防止连续点击重复计分。
- 中文释义在单词右侧，窄屏或长单词时允许换行。
- 鼠标/触摸均可用，也支持键盘 1–4 作答、Enter 继续以及 Tab 导航。
- 不依赖第三方在线资源；首次加载仍需要网络，不包含离线 PWA 缓存。
- 本地尺寸模拟无法代替真实华为平板浏览器，建议上线后用实际设备验收。

## 科目扩展

[src/subjects.js](./src/subjects.js) 定义科目注册表和 `Subject` 接口，每个科目提供 `id`、`name`、`load()` 和 `createQuestion()`。本次页面接入第一个科目（英语）；以后可增加科目选择入口，并复用现有答题流程。当前题目模型是文字补全选择题，不声称已支持任意题型。

需求以 [需求文档.md](./需求文档.md) 为准；后续先记录需求变更，再实现。
